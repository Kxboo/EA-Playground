# Tetherball frontend handlers

The port executes UpdatePreGameInstructions (0x80397988, 92 bytes), OnGameStartAnimComplete (0x803978a8, 12), OnHudLoadComplete (0x803978b4, 80), OnPauseReset (0x80397904, 76), InitializeAptHud (0x8039c1d8, 72), UpdatePostGame (0x80399b60, 128), and UpdateWaitForApocalypse (0x80399be0, 60). State dispatch is 1=pregame, 3=intro (existing Lifecycle method), 8=postgame, 9=wait. Wait returns the native raw word 1 while incomplete and 2 when fade completes; a bool outer dispatch loses this distinction.

FrontendState owns only the previously missing base readiness byte +58, signed postgame choice +5c, and +424 byte. Lifecycle retains HUD-ready +32e, animation-complete +32f and paused +24. ServeState retains pause-menu +4e, pause counter +fc and external FEManager +48/+49 flags. Intro state remains the existing projection from ResetState; this module creates no second owner.

Pregame treats any nonzero +58 as ready. Native ClosePreGameScreen (0x803ab684) clears pregame handlers, closes the screen, starts a 400-ms world fade out, enables fade rendering (false,true), then clears +58. HUD initialization sets both FE flags, selects minigame handler kind 2, and opens the ELF string TetherballHud. It does not set HUD readiness: only the asynchronous OnHudLoadComplete callback hides timer/mega meters and sets +32e. Pregame then changes state to 3 and stores +424=1.

Postgame choice 0 closes the screen, invokes virtual ResetMiniGame at vtable +30, and changes state to 3. Choice 1 closes and changes to 9 (whose existing entry starts fade-in -1); other signed values do nothing. Native ClosePostGameScreen (0x803aba70) clears handlers, closes the screen and stores choice=-1. Pause reset invokes the same virtual full reset, changes state to 3, then executes the base ClosePauseMenu (0x803abbb4): clears paused, closes the overlay, unpauses audio, clears pause-menu-open and stores pause counter=1200. Reset callbacks must run synchronously; the runtime should compose the recovered reset/animation/AI dependencies there.

The pinned-ELF oracle executes all seven original bodies, original ChangeGameState, and the three base close helpers. Hooks are engine/UI/audio singleton access and calls, the fade-completion query, and the virtual full ResetMiniGame dependency. For this isolated 112-call corpus, reset is explicitly a no-mutation service boundary recorded in the ordered trace; these tests do not prove the full reset composition. Cases cover readiness bytes 0/1/2/255, signed choice extremes/-1/0/1/2, both fade outcomes, preserved initial flags/state, and full Lifecycle/ball bits/owned fields plus ordered effects. ServeState bool owners are tested in canonical 0/1 domains; no raw noncanonical byte equivalence is claimed for those fields.

Run `py -3.14 _bevy/tools/tetherball_frontend_oracle.py --check`. The Rust fixture test asserts the ELF hash, compares all lifecycle fields, all ball bits, frontend fields, shared ServeState stores and preservation, raw handler results, and ordered effects. An ignored standalone harness validates this module without a Cargo build.
